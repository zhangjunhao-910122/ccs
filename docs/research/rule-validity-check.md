**结论 1｜湖北现货规则现行版本＝鄂能源调度〔2025〕66 号（V1.0）**
- 现行状态：**现行有效**（截至 2026-11-05 未查到官方替代文件；媒体提到 V3.0，但未取到官方发布页 → 「未查到」）。
- 来源：官方站点原文本机**不可达**（湖北省发改委/省政府 412、湖北电力交易中心 newpmos 412、`nyj.hubei.gov.cn` 与 `www.hbpx.com.cn` DNS 解析失败），已从**第三方镜像 PDF**（`https://yuandian.space/policy-originals/hubei-e4c1cb8b6f.pdf`）核对全文；引用来源笔记：`docs/research/forecast-method-baseline.md`（来源 S1）、`docs/research/hubei-power-market-and-retail.md:42,94`。访问日期 2026-11-05。
- 已核验的关键时间轴（作为结算复现与预测时点口径）：D-1 07:30 前发布次日事前信息；D-1 20:00 前完成省内日前市场正式出清；实时市场每 15 分钟滚动、出清结果在 T-15 分钟前发布；D+1 推送计量与出清结果；D+2 形成每小时实时节点电价，并在当日 24:00 前可提异议。
- 价格边界（附件 6）：市场出清价格上下限 **0–1200 元/兆瓦时**，申报价格上下限 **0–1000 元/兆瓦时** → **现行规则下不出现负电价**。

**结论 2｜南方区域现货规则现行版本＝2026 年 V1.0 版**
- 现行状态：**现行有效**。配套依据：〔关于同意南方区域电力市场转入正式运行的复函〕发改办体改〔2026〕715 号，2026-10-14 成文、2026-10-28 发布，原文 https://www.ndrc.gov.cn/xxgk/zcfb/tz/202610/t20261028_1408423.html ：「一、原则同意南方区域电力市场转入正式运行」；「三、……不断修订完善交易细则……」。访问日期 2026-11-05。
- 原文入口：正文页 http://www.gzpec.cn/law/jygz/202611/t20261103_37339.html ；PDF（185 页）http://www.gzpec.cn/law/jygz/202611/P020261103633894465723.pdf 。访问日期 2026-11-05。
- 条款级摘录（可追溯到条款号）：
  - **2.5 日前出清计算**：「D-1 日 20:30 前，电力调度机构基于经营主体申报信息以及运行日的电网运行边界条件，采用安全约束机组组合（SCUC）、安全约束经济调度（SCED）程序进行优化计算，出清得到日前市场出清结果。」
  - **2.7.1.1 发电侧价格**：「发电侧的日前电能量市场出清形成每 15 分钟的节点电价，每小时内 4 个 15 分钟的节点电价的算术平均值，计为该节点每小时的平均节点电价。日前电能量市场中，发电机组以机组所在节点的小时平均节点电价作为相应时段的结算价格。」
  - **2.2.11.3 电能量申报价格上下限**：「综合考虑一次能源成本、发电企业运营、市场用户电价承受能力等因素，设置电能量申报价格上下限……电能量申报价格上限/下限可根据电力供需形势、一次能源成本等运行情况变化进行动态调整。」
  - **2.2.11.5 市场出清价格上下限**：「……当市场出清得到的节点电价超过市场出清价格上限时，该节点在该交易时段的节点电价用市场出清价格上限代替。当市场出清得到的节点电价低于市场出清价格下限时，该节点在该交易时段的节点电价用市场出清价格下限代替。」（即：**负电价的实际约束手段是价格下限，不是负价专门条款**）
  - **附录 3 区域及省内参数**：电能量申报价格上限/下限、市场出清价格上限/下限、省间关口出清价格上限/下限，取值由各省自定（未确定前用燃煤（环渤海/CECI/广州港指数基准+运价加成）算边际燃料成本×U1、燃气用 JKM 指数×U1 取高；市场出清价格上限按申报价格上限上浮确定）。
- 交叉印证：广西电力市场现货结算实施细则 2026 年 V2.0（http://www.gzpec.cn/law/jygz/202611/P020261103634657295176.pdf ，正文页 t20261103_37340.html ，2026-11-03）全文**无**「尖峰 / 负电价 / 赋价」字样（2026-11-05 核）。

### c. 尖峰时段识别规则与负电价 / 尖峰赋价条款原文

**结论 1｜尖峰时段识别的现行上位规则＝发改价格〔2021〕1093 号（国家层面），省级落地文件原文本机不可达**
- 〔国家发展改革委关于进一步完善分时电价机制的通知〕发改价格〔2021〕1093 号原文（一手）：https://www.gov.cn/zhengce/zhengceku/2021-07/29/content_5628297.htm 。**现行有效**。原文要点：
  > 「（二）建立尖峰电价机制。各地要结合实际情况在峰谷电价的基础上推行尖峰电价机制。**尖峰时段根据前两年当地电力系统最高负荷 95% 及以上用电负荷出现的时段合理确定**，并考虑当年电力供需情况、天气变化等因素灵活调整；**尖峰电价在峰段电价基础上上浮比例原则上不低于 20%**。」
  > 峰谷价差：「上年或当年预计最大系统峰谷差率超过 40% 的地方，峰谷电价价差原则上不低于 4:1；其他地方原则上不低于 3:1。」
- 省级落地：湖北省分时电价机制文件（鄂发改价管〔2024〕77 号）**官方原文页未查到**（湖北省发改委 412），已从宜昌市发改委转载全文核对：http://fgw.yichang.gov.cn/content-63074-983392-1.html （**转载，非一手**，待换正式链接）。访问日期 2026-11-05。
- 尖峰时段的**具体小时清单**：**未查到**（须取湖北省分时电价目录或年度交易方案附件中的尖峰时段表）。可确认的落地口径：湖北 2024 年交易方案按「前两年当地最高负荷 95% 及以上时段」确定尖峰时段并做 4:4:3:1 时段分解（该方案依据里含**已于 2026-03-01 废止**的发改能源规〔2020〕889 号；方案一手 PDF 未查到）。

**结论 2｜负电价：现行规则下不出现负价，但没有「负电价结算条款」**
- 南方区域电力现货市场实施细则 2026 年 V1.0 版全文检索：「尖峰」**0 命中**、「负电价 / 负价格」**0 命中**（唯一近似表述为「每小时用电量不得为负值」，属申报量约束，非负电价）。
- 湖北现货 V1.0：附件 6 出清价下限 **0 元/兆瓦时**、申报价下限 **0 元/兆瓦时** → 现行规则下负电价不出现（来源：`docs/research/forecast-method-baseline.md` / `hubei-power-market-and-retail.md`，镜像 PDF）。
- 结论：**未查到**任何现行细则中「负电价如何出清与结算」的专门条款；负价只能被**价格下限**机制封住（南方区域 2026 V1.0 第 2.2.11.5 条、附录 3）。

**结论 3｜「尖峰赋价 / 尖峰时段加倍或单独限价」：未查到**
- 南方区域 2026 V1.0 中的「赋价」是**节点电价形成机制**，与尖峰无关：2.6.2 特殊赋价原则（「……电价需要采用赋价方式得到。系统按照母线、负荷、机组的顺序依次进行赋价。」）、2.6.2.3 机组孤网赋价、3.5.2 特殊节点赋价（「特殊节点在实时电能量市场中的赋价机制与 3.6.1 一致。」）。
- 广西 2026 现货结算细则 V2.0 全文「尖峰 / 负电价 / 赋价」均 0 命中（2026-11-05 核）。
- 因此：尖峰的**货币化只发生在分时电价侧**（尖峰电价在峰段基础上上浮 ≥20%，发改价格〔2021〕1093 号），**现货结算侧不存在尖峰时段加倍或尖峰限价条款**。

### d. 结算复现科目与公式依据（日清 / 月结 / 偏差费用 / 批零毛利 / 绿电分账）

**零售侧（售电公司视角，最直接可用）——〔湖北省电力零售市场实施细则〕鄂电交易〔2025〕9 号**
- 第六章 零售结算 第三十六条：「零售市场**以月度为周期进行结算**，按月出具结算依据。」→ **月结**口径成立；未见「日清」条款。

- 第三十八条：「零售用户结算电价，按其与售电公司在零售合同中约定的电价结算。」

- 第四十三条（结算凭据）：「电力交易机构统一出具市场主体的电费结算依据，电网企业根据结算依据对售电公司和零售用户出具结算凭据并进行资金结算。」

## 五、规则知识库建议结构（供 #54 规格票直接采用）

**每条规则一条记录，字段如下（不可省略）**：

| 字段 | 说明 / 取值示例 |
|---|---|
| `rule_id` | 稳定主键，如 `HUBEI-SPOT-V1.0`、`GZ-SPOT-2026-V1.0`、`SALE-MGMT-1595` |
| `file_name` | 文件全称（含「实施细则/办法/规则」后缀，如《湖北省电力零售市场实施细则》） |
| `doc_no` | 文号（如 `鄂能源调度〔2025〕66 号`、`发改体改规〔2021〕1595 号`） |
| `doc_level` | 法律 / 行政法规 / 部门规章 / 部门规范性文件 / 省级细则 / 交易中心细则 / 交易方案 |
| `issuer` | 发布机关（湖北省能源局 / 湖北电力交易中心 / 国家发展改革委 / …） |
| `published_date` / `effective_date` | 发布日期 / 施行日期（分离；有效期条款存在时另记 `validity`） |
| `validity` | 原文有效期表述 + 推算到期日（如「有效期 5 年 → 2026-11-10」） |
| `status` | 四态：现行有效 / 已到期 / 已修订 / 未查到（附 `status_evidence`） |
| `chapter_path` | 章节路径（如 `第六章 零售结算`） |
| `clause_no` | 条款号（如 `第三十九条` / `2.7.1.1`） |
| `clause_text` | 原文片段（≤200 字，逐字，不改写） |
| `clause_topic` | 受控词表：结算周期 / 结算电量 / 结算价格 / 批零毛利 / 偏差考核 / 追退补 / 运行补偿 / 偏差费用返还 / 尖峰时段 / 尖峰上浮 / 价格上下限 / 负电价 / 绿电环境价值 / 履约保障 / 信息披露 / 交易日历 |
| `applies_to` | 主体（售电公司 / 发电企业 / 电力用户 / 交易机构 / 调度机构） |
| `data_availability` | 披露频率、颗粒度、保留年限（依据 9 号文第九条＝≥2 年、结构化优先） |
| `source_url` / `accessed_date` | 一手 URL + 访问日期（本轮统一 2026-11-05） |
| `evidence_kind` | 一手原文 / 政府公报 / 官方 PDF / 镜像（镜像须写明镜像渠道与差异风险） |
| `version_chain` | 前版文号 + 替代关系 + 差异点 + 差异取证日期（如 `发改能源规〔2020〕889 号 → 已废止（2026-03-01）`） |
| `pending_change` | 修订/征求意见中的占位（如 `1595 号文：修订征求意见稿 2026-09-04 至 2026-10-04，意见反馈通告 2026-10-12，未印发`） |

**版本对比机制**：每条记录保留 `version_chain` 数组（每个历史版本一条），并单独维护 `pending_change` 与 `diff_todo`（修订稿发布后逐条比对注册条件/履约保障/保底售电/信息披露四组条款）；状态变更以「证据事件」追加（事件：发布/征求意见/废止公告/到期），不覆盖历史。

**引用方式**：平台内一切输出（预测结果、回测报告、影子运行告警、结算复现差异表）统一引用格式 `〔文件全称〕文号 第X章第Y条（版本，生效日）`，机器可解析；规则库记录 `rule_id` 与 `clause_no` 与该字符串一一对应，输出侧只落 `rule_refs[]`，避免文案里手写文件名。

**与三张票的绑定**：`#45` 每个特征字段绑定 `rule_refs[]`（取数口径与时点可得性）；`#39` 输出契约新增 `rule_context` 字段组；`#37` 回测报告的每个拆解项与每条未达标归因绑定 `rule_refs[]`；`#54` 规格直接引用本结构。
