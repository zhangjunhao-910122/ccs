## 字段说明

`扫描结果总表.tsv` 列：`id / category / name / url / http_code / size / ctype / time / redirects / dns / sha10(sha16) / title / flags / final_url / error`

- `http_code`：本次实测返回的 HTTP 状态码；`000` 表示连接层失败（DNS 解析失败或连接超时）。
- `size`：响应体字节数（未完成下载时为已读字节数）。
- `sha16`：响应体 SHA256 前 16 位（二进制源用于唯一标识与后续核对）。
- `flags`：`PDF` / `OLE_DOC` / `ZIP` / `EXC`（非 HTML 文件）/ `SPA_MARKER`（前端空壳）/ `AUTH_HINT`（登录页特征）/ `JS_RENDER_TEMPLATE`（正文由 JS 渲染）/ `BLOCK_4xx` / `DOMAIN_FOR_SALE`（域名停售）/ `SMALL_HTML`。
- `dns`：本次会话解析到的 IP 列表；为空表示解析失败。
