# ISO 质量审核员「全流程审核」流程骨架（研究结论）

- 调研日期：2026-11-05
- 调研目的：为「ISO 质量审核员全流程审核智能体」项目确定「审核流程骨架」——即一次管理体系（QMS）认证审核从受理到获证后监督、再认证之间，各阶段的目的、输入、动作、输出与责任角色。
- 来源分级标记：
  - **【一手】** = 监管/认可机构/标准组织官方文本，或本机已保存的官方文本副本。
  - **【二手】** = 认证机构面向客户的公开告知函、第三方机构解读、媒体报道（用于补足一手 PDF 未取到部分的条款细节，需回一手核验）。
- 一句话结论：**流程骨架以 CNCA《质量管理体系认证规则》（一手，本机 `.research-tmp/cnca_qms_rule_2016.txt` 为 2016 版全文；现行版为 CNCA-QMS-01:2025，一手公告页见 §1.1）为主干，以 CNAS-CC01（内容与 ISO/IEC 17021-1:2015 条款号一致，一手，见 `.research-tmp/CNAS-CC01-2015.txt`）为机构侧约束，不以任何企业官网为依据。**

## 2. 「北京联合置业有限公司」官网查找结果（如实记录）

### 2.1 企业性质

**它是房地产开发／代建企业，不是认证机构。** 成立于 2002-06-18（北京市东城区），注册资本 61994.584 万元人民币，中国交建（601800）体系内企业；2018 年 12 月中交地产（000736）公告以 8.66 亿元收购其 100% 股权；2020-03-13 正式更名为「中交房地产管理集团有限公司」（主营房地产代建／项目管理），后续公开资料中亦见「中交房地产集团有限公司」。
来源：https://www.newton.com.tw/wiki/北京聯合置業有限公司/20537817 ；https://paper.cnstock.com/html/2018-12/12/content_1095563.htm ；https://finance.sina.com.cn/other/lejunews/2020-03-17/doc-iimxyqwa1251081.shtml ；https://m.bjnews.com.cn/detail/158436953014082.html ；https://www.tedahu.com/zhongjiao/zixun/idd790.html （均为二手）

- 补充旁证：其官网确实有供应商准入／品质管控类要求（招聘页提到「制定和完善公寓品质管理标准、流程及考核机制，建立监督与评估体系」 https://m.zhaopin.com/jobs/CCL1469300150J41019410504.htm ，二手），但那是**采购方对供应商的内部品质审核**，属企业内部审核，与认证机构审核不可混用。

### 2.3 结论（为何不能用它作流程参考）

**不能用「北京联合置业有限公司」（中交房地产管理集团）官网作为审核流程参考：它是房地产开发／代建企业而非认证机构，官网公开的「标准体系」是产品与交付标准，且抓取不到任何认证审核程序页面；本项目的流程骨架一律以一手文件为准——CNCA《质量管理体系认证规则》（本机 `.research-tmp/cnca_qms_rule_2016.txt` 为 2016 版全文，现行版 CNCA-QMS-01:2025 公告页见 §1.1）与 CNAS-CC01（内容与 ISO/IEC 17021-1:2015 条款号一致，本机 `.research-tmp/CNAS-CC01-2015.txt`）。**

> 官网未找到与「体系审核／认证流程／认证证书」相关的公开内容，如实记为：**未找到**（其官网页面正文本次全部抓取失败，无法排除极冷门页面存在，但已检索到的栏目体系中不存在此类内容）。

## 4. 各阶段详解

### 阶段 0：受理、合同评审与申请条件审查

| 项 | 内容 |
|---|---|
| 目的 | 确认申请人具备申请资格、申请资料齐备、认证范围可界定，并与委托人建立有法律效力的认证合同，明确双方责任。 |
| 输入材料 | 认证申请书；法律地位证明（营业执照等）；行政许可、资质、强制性认证证书复印件（如适用）；管理体系成文信息（质量手册、程序文件、关键过程文件）；**现行版新增**：QMS 运行满 3 个月的证据、一年内质量事故／与质量相关的行政处罚／国家监督抽查及其他抽查不合格情况与整改情况。【一手】4.1.2（` .research-tmp/cnca_qms_rule_2016.txt`）；新增项见【二手】BCC 5.1.3（http://www.bcc.com.cn/index/shows?catid=3&id=231）、CEC 5.1.2(4)（https://www.mepcec.com/rzfw/txrz/zlgltx/gkwj/2025/13205.shtml） |
| 关键动作 | ① 公开认证机构自身的申请信息、程序与收费（4.1.1）；② 能力评审：判断申请组织是否属应予受理范围（4.1.3）；③ 受理决定并签订认证合同（4.1.4、4.1.5）；④ 转换认证时另核原发证机构资格（现行版 5.2.3，【二手】BCC）。 |
| 输出物 | 受理决定；**认证合同**（含持续有效运行承诺、通报义务、不得误导使用证书等 7 项内容，4.1.5）；申请评审记录；审核范围初稿；认证费用与日程安排。 |
| 责任角色 | 认证机构：申请受理／合同评审岗（对受理与合同负责）；认证委托人：提供资料、签署合同、支付费用（现行版 5.3.1 要求直接支付、不得第三方支付，【二手】CEC）。 |
| 常见退回原因 | ① 申请组织被责令停产停业整顿或列入严重违法企业名单（4.1.3）；② 体系运行不足 3 个月或无法提供运行证据（FAQ 第 8 问口径：本机 `.research-tmp/cnca_faq.html.txt`）；③ 因自身原因被原发证机构暂停／撤销／注销证书未满一年（现行版 5.1.2(4)，【二手】CEC/BCC）；④ 一年内发生重大质量事故，或认证范围内产品国家监督抽查不合格且未整改合格（【二手】BCC 5.1.2）；⑤ 申请资料不全、法律地位证明缺失（4.1.2）；⑥ 费用非委托人直接支付（现行版 5.3.1，【二手】CEC）。 |

### 阶段 1：资格审核（第一阶段审核）+ 审核策划

| 项 | 内容 |
|---|---|
| 目的 | 验证申请组织的体系文件与现场实际一致、体系已真实运行并具备实施认证审核的条件；据此确定审核范围、重要审核点与第二阶段安排。【一手】4.3.3（第一阶段） |
| 输入材料 | 管理体系成文信息（手册、程序文件、关键记录）；内审与管理评审记录及有效性证据；场所／人数／活动／过程信息；法律法规清单；重要产品／服务与关键过程说明；上一阶段（转换／其他机构证书）资料。 |
| 关键动作 | ① **审核策划**：确定审核时间（现场审核时间不少于总审核时间的 80%；特殊情形可减时，累计不超过 30%，4.2.1；低风险组织可减时不超过附录 B 的 10%，FAQ）；组建审核组（审核员＋技术专家＋实习审核员，4.2.2）；编制书面审核计划（目的、准则、范围、日期与场所、持续时间、审核组成员及其注册号；第一阶段不要求编制正式审核计划，多场所可抽样，4.2.3）。② **第一阶段至少覆盖 5 项**（4.3.3）：成文信息与现场实际一致性；内审与管理评审的有效性，并确认体系已运行超过 3 个月；申请范围是否覆盖全部要求场所、人员、活动与过程及法律法规的符合性；识别重要审核点；与申请组织讨论第二阶段安排。③ **第一阶段能否非现场**（4.3.3.3）：仅限持本机构有效证书、技术特征明显且过程简单可文件审查达到目的、持其他认可机构颁发的有效证书三种情形；其余情形必须实施现场审核。第一阶段完成后须形成书面文件告知申请组织并提醒重要审核点（4.3.3.4）。④ 判定审核范围要素（见 §5.2）。 |
| 输出物 | 审核策划文件／审核计划；第一阶段发现清单与重要审核点清单；第一阶段书面告知文件；审核范围确认单；审核人日测算（CNAS-CC105:2020＝IAF MD5:2019，附录 A 人日表）；审核组任务分工。 |
| 责任角色 | 审核组长（编制计划、带组）、审核员（专业审核）、技术专家（专业支持）、认证机构审核策划／管理者（人日与范围批准）。 |
| 常见退回原因 | ① 体系文件与现场实际不一致（4.3.3 第 1 项）；② 体系运行不足 3 个月、内审或管理评审缺失／无效（4.3.3 第 2 项、FAQ 第 8 问）；③ 申请范围未覆盖全部应覆盖场所／人员／活动／过程，或法律法规不落实（4.3.3 第 3 项）；④ 范围界定不符合 CNAS-EC-015 的四要素／六要素（` .research-tmp/CNAS-EC-015.txt`）；⑤ 审核时间不足 80% 现场比例且无合规减时理由（4.2.1、FAQ 第 12 问）；⑥ 审核组能力不匹配（缺少相应专业注册审核员／技术专家，4.2.2；FAQ 第 9 问审核员 QMS 现场审核时间 ≤180 天/周期年、第 10 问人均有效证书 ≤50 张/周期年）。 |

### 阶段 2：现场审核（第二阶段）+ 审核报告

| 项 | 内容 |
|---|---|
| 目的 | 获取认证范围覆盖范围内管理体系运行的客观证据，确认体系有效运行并符合认证要求，形成审核结论与不符合项。【一手】4.3.3（第二阶段）、4.4 |
| 输入材料 | 第一阶段输出与重要审核点清单；审核计划与检查表；现场记录、抽样清单；受审核部门的作业文件与记录。 |
| 关键动作 | ① **首、末次会议**（4.3.2）：首次会议说明审核目的、范围、准则、方法、日程、抽样说明与确认联络人；末次会议通报审核结论与不符合项。首末次会议签到表须保留（现行版进一步要求保留签到记录与图片／音像证明材料，最高管理者缺席须由书面授权的高级管理层成员参会并记录缺席理由，【二手】CEC 5.5.3）。② **第二阶段至少覆盖 5 项**（4.3.3.5）：重要审核点的过程控制有效性；质量目标是否具体、可测量并得到监视与沟通；对过程和活动的管理控制；记录（信息）的真实性；内审与管理评审的有效性。③ 抽样与证据获取：访谈、观察、查记录，形成可追溯的审核发现；④ 重点审核最高管理者在管理体系中的领导作用（现行版 5.5.4：不熟悉本组织质量方针／质量目标、未亲自参与推动 QMS 实施的，审核不予通过，【二手】CEC）；⑤ **终止审核**的 4 种情形（4.3.4／现行版 5.5.5）：委托人不予配合致审核无法进行；最高管理者或经授权高级管理层缺席首末次会议；实际情况与申请材料重大不一致；其他导致审核程序无法完成。⑥ **审核报告**（4.4）应含 8 项内容：受审核组织名称与地址；认证范围与场所；审核类型、准则、目的；审核组组长与成员及其注册信息；审核日期与地点（含临时现场与偏离说明）；对审核工作与审核结论的逐项描述；不符合项；是否通过认证的建议。审核报告应在作出认证决定后 30 个工作日内提交申请组织（4.4.3）。 |
| 输出物 | 首次会议记录与签到表；末次会议记录与签到表；审核记录与检查表；不符合项清单（按严重／一般分级）；审核报告（含是否通过认证的建议）；审核证据留存。 |
| 责任角色 | 审核组长（主持首末次会议、出具报告）、审核员与技术专家（取证与判定）、认证委托人方最高管理者与各职能部门负责人（参加首末次会议、提供证据）、认证机构（报告审核、留档）。 |
| 常见退回原因 | ① 首末次会议最高管理者缺席且无书面授权（4.3.2、现行版 5.5.3）；② 记录不真实、过程控制失效（4.3.3.5）；③ 质量目标不可测量／未监视沟通；④ 内审与管理评审流于形式（4.3.3.5）；⑤ 审核报告内容缺项（4.4 的 8 项）；⑥ 触发终止审核情形（4.3.4）；⑦ 现行版：最高管理者未亲自推动 QMS 实施（【二手】CEC 5.5.4）。 |

### 阶段 3：不符合项与纠正措施验证

| 项 | 内容 |
|---|---|
| 目的 | 确保不符合项得到纠正并采取纠正措施防止再发，闭环后方可进入认证决定。【一手】4.5 |
| 输入材料 | 审核报告与不符合项清单；委托人的纠正与纠正措施方案及证据；必要时再次现场验证的申请。 |
| 关键动作 | ① 委托人提交纠正（解决不符合）与纠正措施（防止再发生的措施）；② 审核组／认证机构验证措施的有效性与完成情况；③ 严重不符合的验证时限约束（2016 版：严重不符合应在 6 个月内完成验证，4.5）；④ 现行版时限口径：监督审核不符合 3 个月内未完成验证 → 暂停或撤销证书；再认证不符合未在证书到期前完成验证 → 证书到期自动失效；未按时限完成措施不应作出授予／保持／更新决定（【二手】CEC 5.10.4）。 |
| 输出物 | 纠正措施方案与证据包；验证结论（关闭／维持不符合）；不符合项关闭记录；进入认证决定的输入结论。 |
| 责任角色 | 认证委托人（责任部门与管理者，负责纠正与措施）；审核组（验证有效性）；认证机构（确认闭环）。 |
| 常见退回原因 | ① 只做纠正不做纠正措施（无根因分析、无防再发机制）；② 措施证据不足以证明有效；③ 严重不符合超期未验证（2016 版 6 个月上限；现行版 3 个月／到期前时限，【二手】CEC）；④ 措施未落实到体系文件或作业层面的变更。 |

### 阶段 4：认证决定与发证

| 项 | 内容 |
|---|---|
| 目的 | 由具备独立性的认证决定人员基于完整审核证据作出是否认证的决定，并颁发证书、办理备案。【一手】4.6、4.8 |
| 输入材料 | 申请评审记录与认证合同；第一、二阶段审核记录与审核报告；不符合项及验证结论；适用时其他审核（如结合审核）的记录。 |
| 关键动作 | ① 认证决定由未参与该项审核的认证决定人员作出（4.6.2）；② 作出决定前进行确认（如审核覆盖范围与申请范围一致、审核组成员独立性与能力、不符合项已闭环、审核报告与证据一致等 4.6.3 所列确认）；③ 存在不符合认证要求情形的不予认证（4.6.5）；④ 作出决定后 30 个工作日内向 CNCA 报送（4.6.6）；⑤ 审核报告在认证决定后 30 个工作日内提交申请组织（4.4.3）；⑥ 证书内容（4.8.1）须含八项信息，其中明确可在 www.cnca.gov.cn 查询；证书初始有效期最长 3 年（4.8.2）；现行版要求证书列明现行有效标准名称及标准号（FAQ）。 |
| 输出物 | 认证决定记录（批准／不予批准／暂缓）；认证证书；CNCA 备案记录；获证组织信息录入（供 www.cnca.gov.cn 查询）。 |
| 责任角色 | 认证决定人员／技术评审岗（与审核活动独立）；认证机构管理者（批准发证与备案）；认证委托人（获证后权利义务确认）。 |
| 常见退回原因 | ① 决定人员参与了该项审核（违反独立性，4.6.2）；② 审核范围与申请／证书范围不一致；③ 不符合项未闭环；④ 申请材料或体系运行条件与审核期间实际不一致（触发终止审核情形）；⑤ 证书信息项不完整或未列现行有效标准名称及标准号（FAQ）。 |

### 阶段 5：获证后监督（首次监督／年度监督／特殊监督）

| 项 | 内容 |
|---|---|
| 目的 | 持续确认获证组织体系持续有效运行，处理体系与法规变化，维持证书有效性。【一手】5 |
| 输入材料 | 获证组织的体系运行与变更信息（重大变更、法律要求变化、投诉与处理、质量目标达成情况、认证标志使用情况）；监督审核计划。 |
| 关键动作 | ① 首次监督审核在初次认证证书签发之日起 12 个月内进行，此后监督审核间隔不超过 12 个月（2016 版：首次 ≤12 个月、间隔 ≤15 个月；现行版 5.4.1.4：间隔 ≤12 个月、一个认证周期至少两次监督审核，超期必须暂停并上报，暂停期满仍未执行必须撤销并上报，【二手】CEC）；② 国家监督抽查不合格的，自通报起 30 日内实施监督审核（2016 版 5.2.3；现行版 5.9.3 为「提前较短时间通知的审核」，【二手】CEC）；③ 监督审核时间不少于初次认证审核人日的 1/3（5.3）；④ **监督审核至少审核 8 项**（5.6）：获证组织的重大变更；上次审核发现的重要关键点是否持续有效运行；上次不符合项的纠正措施是否继续有效；法律法规的持续符合；质量目标与绩效是否达成；认证标志使用是否合规；内审与管理评审的运行情况；投诉处理与改进措施；⑤ 监督结论与证书处置：保持／暂停／撤销决定（5.9）。 |
| 输出物 | 监督审核计划与报告；监督不符合项及验证结论；证书保持／暂停／撤销决定；暂停或撤销后在网站公布并报 CNCA（7.4）。 |
| 责任角色 | 审核组（实施监督审核）；认证机构（安排监督计划、作出证书处置决定）；获证组织（配合审核、变更通报、接受监督）。 |
| 常见退回原因 | ① 未在间隔内接受监督审核（超期 → 暂停／撤销，【二手】CEC 5.4.1.4）；② 上次不符合纠正措施不再有效；③ 重大变更未通报；④ 认证标志使用违规；⑤ 质量目标未达成且无改进；⑥ 投诉处理不当（5.6）。 |

### 贯穿性环节：申诉、记录与档案

- **申诉**：对认证决定有异议，应在规定时限内提出（2016 版：认证机构在收到申诉后 60 日内作出书面答复，11）。
- **记录管理**（12）：认证记录使用中文，保存期限不短于证书有效期，电子文档须为不可编辑格式。
- **审核员能力约束**（3）：QMS 现场审核时间合计不超过 180 天/周期年、人均有效认证证书不超过 50 张/周期年；境外审核员在境内实施 QMS 认证需经中国认证认可协会确认（FAQ，第 9、10 问及外籍审核员问答）。

## 5. 横向要求（对智能体建模直接相关）

### 5.1 审核范围与审核准则

- **准则**：管理体系标准（QMS 现行版为 GB/T 19001-2016，对应 ISO 9001:2015；国际层面已被 ISO 9001:2026 取代，见 §6）＋ 法律法规要求 ＋ 组织自定的体系文件。
- **范围四要素**（CNAS-EC-015:2011，引 GB/T 19011-2013 术语 3.14）：实际位置、组织单元、活动和过程、覆盖的时期。**QMS 审核范围六要素**：产品／服务范围、业务活动范围、管理职能范围、现场区域范围、法律法规要求、覆盖时间段。来源：` .research-tmp/CNAS-EC-015.txt`（该文件明示「本文件内容不是一项要求，仅旨在为……提供指导性帮助」）。
- **审核方法依据**：GB/T 19011-2021《管理体系 审核指南》现行有效，GB/T 19011-2013 已废止（` .research-tmp/d_19011_a.txt`、` .research-tmp/d_19011_b.txt`）。

### 5.2 时间与人日

## 7. 流程骨架的两种读法

同一句「ISO 质量审核员」，在实务中指两种完全不同的角色，其流程骨架不可混用。

### 7.1 读法 A：第三方认证审核（对外 certification audit）

- **主体**：获认可（CNAS 认可或境外认可机构认可）的认证机构；执行人为注册审核员／技术专家。
- **目的**：判定组织是否符合管理体系标准，出具认证证书并维持其有效性（具有对外的、具法律效力的结论）。
- **流程**：受理与合同评审 → 第一阶段（资格／文件＋现场）→ 第二阶段（现场审核＋首末次会议＋审核报告）→ 不符合项与纠正措施验证 → 认证决定（独立于审核活动）→ 发证与备案 → 监督（首次／年度／特殊）→ 再认证 → 暂停／撤销 → 申诉与记录管理。
- **关键约束**：现场比例 ≥80%、人日表、审核员年度工时与证书数上限、第一／第二阶段可核减项、决定人员独立性、证书 3 年有效期、CNCA 备案与网站可查。
- **来源**：` .research-tmp/cnca_qms_rule_2016.txt` 全文（4→12）；现行版条款号见 §1.2 二手两件；` .research-tmp/CNAS-CC01-2015.txt`（机构侧要求，条款号同 ISO/IEC 17021-1:2015）；` .research-tmp/CNAS-EC-015.txt`（范围）。

### 7.2 读法 B：企业内部管理体系审核（对内 internal audit）

- **主体**：组织自己的管理者与内审员（对内审核是组织针对自身管理体系自主实施的系统、独立评价活动）。
- **目的**：验证体系符合标准与内部要求、运行有效，为管理改进与管理评审提供输入，**不产生认证证书**。
- **流程（参照 CNAS-GL011:2025 的内审骨架，实验室与检验机构领域，属类比参考）**：
  1. 内审要求与程序：建立内审工作程序，明确内审周期与频次、审核准则、职责分工、过程控制（策划—实施—结果报告—后续措施）、记录要求；内审周期与覆盖范围应基于风险分析，建议覆盖全部场所与全部活动（4.1、4.2）。
  2. 内审资源与公正性：配置内审资源与内审员能力覆盖受审核活动；当内审员不能独立于受审核活动时，增加共同审核人员或由相关人员评估结果的客观性、公正性；可聘请外部人员协助但需预先评价其能力（4.3、4.4）。
  3. 策划：确立审核目标、准则、范围、时间、审核方法、方案与计划（5.1—5.3）。
  4. 实施：准备（检查资源、阅读成文信息与以往内审结果）、编制内审检查表、启动（首次会议或告知方式）、实施审核（收集验证证据：核查文件、提问、观察、检查设施设备、查阅记录；形成审核发现，含符合性、不符合、观察项、改进建议，基于客观证据且可追溯）（6.1—6.3）。
  5. 报告与后续：审核报告；后续纠正措施及关闭；内审记录（6.4、7、8）。来源：` .research-tmp/CNAS-GL011-2025.txt`。
  6. 与外部审核的接口：外审前的内审与管理评审有效性，本身是外审第一、二阶段的必查项（2016 版 4.3.3、4.3.3.5；FAQ）。
- **与读法 A 的最大差异**：无认证决定与发证、无证书与监督周期、不需要 CNAS 备案；但**审核准则、审核方法、证据可追溯、审核发现分级、后续措施闭环**这些内核与 GB/T 19011-2021 一致。

### 7.3 对照表

| 维度 | 读法 A：第三方认证审核 | 读法 B：企业内部审核 |
|---|---|---|
| 执行者 | 认证机构注册审核员／技术专家 | 本组织内审员（可含共同审核员／外部协助） |
| 触发 | 组织申请认证（+ 年度监督／再认证） | 体系策划与风险分析（周期性 + 专项触发） |
| 关键文件 | 认证合同、审核计划、审核报告、认证决定、证书 | 内审程序、内审方案／计划、内审检查表、内审报告、后续措施记录 |
| 输出效力 | 对外有效，可用于招标、客户证明 | 对内有效，支撑管理评审与改进 |
| 决定环节 | 认证决定（独立于审核活动）+ 发证 + 备案 | 无发证；由管理者主持内审与后续措施跟踪 |
| 时间与频次 | 初次两阶段 + 监督（间隔 ≤12 个月）+ 再认证 | 按内审周期与风险确定覆盖范围与频次 |
| 记录保存 | 不短于证书有效期，电子文档不可编辑 | 留有内审记录与报告，支持追溯 |

**结论**：用户所说「ISO 质量审核员」的角色尚未确认，两种读法都需保留。若智能体面向外部认证机构，应按读法 A 的阶段与产物建模（合同—计划—首末次会议—审核报告—不符合验证—决定）；若面向企业内部，则按读法 B 建模（程序—方案—检查表—报告—后续措施）。两者可共用底层能力：审核准则库、审核方法（GB/T 19011-2021）、证据与审核发现的分级与描述规则、不符合项到纠正措施的闭环跟踪。
