# GB/T 45001-2020 条款级审核点基线

本文件是一份面向审核员的条款级审核点基线。每一个条款配一张固定四行的审核卡：审核问题、需索取书面证据、现场核查证据、常见不符合项，供内部审核策划、体系自查与现场抽样检查直接取用。文件只写条款号、条款标题与自研的审核问题、证据要求，不复制受版权保护的标准正文。

## 0 说明

- **标准号与版本**：本文件的条款号与条款标题取自 GB/T 45001-2020 官方目次（已取得一手转录）；该标准等同采用 ISO 45001:2018 IDT，于 2020-03-06 发布并实施；中文条款标题与条款正文仍须用正版正文逐条核定。
- **依据来源**：依据 GB/T 45001-2020 官方目次（已取得一手转录）确定条款号、条款标题与子条款归属，审核问题、证据要求与不符合项描述全部自研。**本文件不是标准原文，未复制任何标准条款正文。**
- **适用范围**：适用于以 GB/T 45001-2020 建立并保持职业健康安全管理体系、实施内部审核与管理体系评价的组织及其场所；供内部审核员、体系维护人员、外审策划人员作为审核准备与抽样清单使用，也可作为供应商现场评价的提问工具。
- **准确性声明**：条款号、条款标题、条款层级归属与“应/不应”的判定尺度均须以正版标准正文为准，**须用正版标准逐条核定**；本文件给出的审核问题与证据清单是审核实践工具，不构成标准解释，也不构成合格判定依据。
- **正版核定的责任归属**：由体系归口管理部门（通常为质量/职业健康安全归口办）负责获取正版标准文本并逐条核对，在对外出证、判定不符合项、编写审核方案前完成核定，责任人为该归口部门负责人；本基线的编写与维护责任在本文件维护者。审核员在使用中发现本文件条款标题或子条款归属与正版文本不一致时，一律以正版文本为准，并回写修订本文件。
- **字段口径**：“需索取书面证据”指审核前向受审核方书面索取的文件、记录、台账与说明，证据本身可以是文件也可以是记录；“现场核查证据”指在现场通过观察、访谈、追溯实物与原始记录取得的事实性证据。两栏均以“可核查”为底线，不接受“已建立体系”“已按要求执行”一类无法验证的陈述。
- **版权边界**：仅引用条款号与条款标题用于定位，不逐条复制标准段落；引用第三方公开目录仅用于结构重建，不作为依据来源的权威性背书。

## 1. 条款级审核点基线

### 1.1 第 4 章 组织所处的环境

#### 4.1 理解组织及其所处的环境

| 项目 | 内容 |
|---|---|
| 审核问题 | 组织如何确定与其职业健康安全管理体系相关的内部因素与外部因素？识别过程是否覆盖法律法规要求、相关方需求与期望、组织规模与场所条件、员工能力与安全文化、既有事件与应急状况等维度？环境分析结论是否转化为 4.2 的相关方要求与 6.1 的风险和机遇，而非停留在清单本身？ |
| 需索取书面证据 | 组织环境识别过程的文件或作业指导；内部因素与外部因素识别清单及最近一次评审记录；环境分析与风险和机遇清单之间的对应关系表；环境识别结果的更新频次与触发条件说明；新场所、新业务、新法规变化对环境识别的影响评估记录 |
| 现场核查证据 | 访谈安全、EHS、设备、人力、采购等不同部门，确认其提供的环境信息确实进入了识别清单；核对清单是否覆盖生产现场、公用工程、检维修、仓储与外包场所等实际变化点；追溯最近一次工艺或场所变化是否进入环境识别与风险评价；向一线了解其知晓的重大变化事项及是否被识别为环境因素 |
| 常见不符合项 | 环境识别停留在体系建立当年的静态清单，近年扩产改造、工艺变更、场所搬迁、法规修订或新业务领域未纳入；环境分析结果没有传递到 6.1 风险评价与 4.2 相关方要求，风险和机遇清单与环境分析互不引用；识别由单一部门闭门完成，内容与现场实际不符；环境变化无人负责更新，识别结果长期不复审 |
> 待核实：4.1 的正式条款标题与是否下设子条款，须用正版正文逐条核定。

#### 4.2 理解工作人员和其他相关方的需求和期望

| 项目 | 内容 |
|---|---|
| 审核问题 | 组织如何确定与其职业健康安全管理体系相关的相关方及其需求和期望？相关方是否覆盖法律法规与其他要求方、工作场所内的各层人员与承包商、供方、客户、监管机构、社区与公众等类别，并分别确定接口与责任部门？工作人员与其他相关方的需求和期望是否被监视、评审，并在发生变化时转化为体系策划输入？ |
| 需索取书面证据 | 相关方清单及其需求事项、责任部门与沟通方式的对应表；合同与协议中的职业健康安全条款（客户、供方、承包商）；相关方需求与期望的监视与评审记录；员工意见与承包商反馈的收集与处置记录；客户投诉、监管意见与外部反馈的处理记录；相关方需求变化触发的体系文件评审与修订记录 |
| 现场核查证据 | 抽查客户或供方合同中的安全条款，核对其与本组织体系要求是否一致；向一线人员了解其对客户与供方安全要求的知晓程度；查看外部投诉、举报与监管意见的处理闭环及结果反馈；验证外部要求发生变化后是否实际修订了体系文件与作业标准；核实工作人员与其他相关方的需求是否真的进入了策划过程，而非只登记在册 |
| 常见不符合项 | 把相关方等同于顾客满意度，忽略员工家属、监管机构、社区、非正式工等直接相关方；合同条款与体系文件形成两套并行要求且未做对齐检查；相关方要求有评审无处置，或评审后不修订体系；与承包商、分包方的安全要求未写入合同，形成体系边界之外的管控空白；外部投诉只做赔付不做体系改进 |
> 待核实：4.2 的正式条款标题与是否下设子条款，须用正版正文逐条核定。

#### 4.3 确定职业健康安全管理体系的范围

| 项目 | 内容 |
|---|---|
| 审核问题 | 体系范围如何确定并形成文件？范围是否覆盖组织的所有场所、所有活动与所有人员，包括承包商、临时用工、劳务派遣与访客？是否存在被排除的场所或活动，排除是否有充分理由且不影响法律法规符合性与职业健康安全风险的降低？范围文件与实际场所清单、实际业务范围是否一致？ |
| 需索取书面证据 | 管理体系范围文件，明确场所、过程、活动与人员边界；场所清单与承包商清单；范围变更（新增或撤销场所、变更业务范围）的评审与批准记录；被排除场所或活动的说明及其风险论证；范围与登记证照、许可范围的对应关系 |
| 现场核查证据 | 将范围文件所列场所与现场实际厂房、仓库、施工区、办公场所逐一对照，核查有无未纳入的场所；查看多法人、多场所之间的体系边界划分与接口人安排；确认门卫、保洁、供方送货、施工等非正式进入场所的人员是否被纳入作业管控；核实排除项的实际影响范围是否与说明相符 |
| 常见不符合项 | 范围只覆盖生产主厂区，忽略仓储、办公场所、外包场地、员工宿舍与食堂；场所清单与实际不符，新厂区、新生产线投产后未纳入体系；使用“情况特殊”“暂不具备条件”等笼统理由排除区域而不做风险论证；承包商与劳务派遣人员的作业被排除在范围之外；范围描述使用功能名称而非可核对的具体场所，难以验证 |
> 待核实：4.3 的正式条款标题与是否下设子条款，须用正版正文逐条核定。

#### 4.4 职业健康安全管理体系

| 项目 | 内容 |
|---|---|
| 审核问题 | 组织如何建立、实施、保持并持续改进职业健康安全管理体系？体系所覆盖的过程与活动如何确定，各过程的输入输出、顺序与相互作用、准则与方法、资源、职责权限、绩效指标与改进方式是否明确？体系的范围与边界是否与 4.3 的范围文件保持一致？体系与职业健康安全方针（5.2）、目标（6.2）、风险和机遇（6.1）如何衔接？4.1 的内外部因素与 4.2 的相关方需求如何体现在体系过程要求与策划输入中？体系在环境变化时是否被评审并保持完整与有效？ |
| 需索取书面证据 | 体系建立与保持的总体策划文件，含体系过程清单与过程关系说明；各体系过程的策划记录（输入输出、顺序与相互作用、准则与方法、资源、职责权限、绩效指标、改进方式）；体系范围与 4.3 范围文件的一致性对照说明；体系与方针、目标、风险和机遇之间的对应关系表；内外部因素与相关方需求进入体系策划输入的记录；体系有效性评价与体系结构变更评审记录（组织架构、场所、工艺、承包商范围变化时） |
| 现场核查证据 | 抽取一条实际业务过程做端到端追踪，核对体系文件描述的过程顺序与现场实际流转是否一致；向部门负责人追问其过程在体系中的位置、上游输入与下游输出是否与文件表述一致；核对现场实际做法与体系策划结论的差异是否已被识别并触发改进；检查体系各文件对同一过程的描述是否自相矛盾；验证扩产、并购、场所搬迁或外包范围变化后是否做过体系结构性调整评审 |
| 常见不符合项 | 体系只有一本手册加几张流程图，没有过程策划与保持记录，文件写的过程与现场实际两张皮；体系过程之间无顺序与相互作用说明，接口处问题无人负责；体系与方针、目标、风险和机遇各自独立编写、互不引用，形成四本互不相干的账；环境变化与相关方需求变化未引起体系调整，体系长期不适配业务；体系范围与 4.3 范围文件不一致，一处包含承包商作业而另一处不包含；体系被当作文件体系维护，无过程改进与有效性评价记录 |
> 待核实：4.4 的正式条款标题是否为“职业健康安全管理体系”，以及其与 7.5 文件化信息的分工，须用正版正文逐条核定。

### 1.2 第 5 章 领导作用和工作人员参与

#### 5.1 领导作用和承诺

| 项目 | 内容 |
|---|---|
| 审核问题 | 最高管理者如何体现对体系的领导作用与承诺？是否承担体系有效性的责任、提供资源、建立沟通渠道、确保要求融入业务过程？是否保证体系与组织的战略方向和业务过程相容？是否亲自推动持续改进？是否对工作人员的协商和参与机制给予公开支持？ |
| 需索取书面证据 | 管理评审记录中最高管理者的主持与决策痕迹；职业健康安全方针及其批准与发布记录；管理体系与战略方向、业务过程衔接的说明与评审证据；资源投入与专项预算的审批记录；最高管理者参与安全活动的纪要、签到与指令性文件；内部与外部沟通渠道的设立与运行记录 |
| 现场核查证据 | 与最高管理者及分管负责人访谈，考察其能否说出本组织头号职业健康安全风险、年度目标完成情况与尚未关闭的重大问题；查看其签发的整改指示与资源审批是否被业务部门落实；观察其参与一线巡查、应急演练或承包商访谈的痕迹；核对承诺事项在体系文件与部门目标中的落地情况 |
| 常见不符合项 | 领导承诺只停留在文件层面，缺少资源决策与个人参与的可核查证据；体系被整体推给安全部门，最高管理者说不清关键风险与目标实况；沟通渠道形同虚设，员工反映的问题从未进入决策层；领导承诺未与战略、预算和业务过程建立联系，仅挂在体系文件里；最高管理者在文件上署名但实际不参与、不决策，承诺无人兑现 |
> 待核实：5.1 的正式条款标题与是否下设子条款，须用正版正文逐条核定。

#### 5.2 职业健康安全方针

| 项目 | 内容 |
|---|---|
| 审核问题 | 组织如何制定、批准和发布职业健康安全方针？方针是否与组织的目的、战略方向和运行环境相适应，是否满足法律法规及其他要求，是否包含持续改进承诺，是否为职业健康安全目标提供框架？方针如何沟通、理解和在组织内保持一致，使各层级人员知晓其含义与自身岗位的关系？方针的制定是否经过与工作人员的协商，并在需要时评审和修订？ |
| 需索取书面证据 | 职业健康安全方针文本及最高管理者批准与发布记录；方针制定与评审记录，含与战略方向、法律法规要求、员工意见的对照说明；方针与职业健康安全目标（6.2）的对应关系说明；方针沟通与宣贯记录，含班前会、培训签到、看板与电子屏发布痕迹；方针文本在办公场所、作业现场与承包商作业点的张贴或发放记录；方针评审与修订记录及修订后的重新沟通记录 |
| 现场核查证据 | 现场随机抽查各层级人员，请其用自己的话说明方针的含义、与本岗位的关系及其对日常作业的实际影响；核对办公区、车间、门卫、食堂与承包商作业点的方针版本是否一致、是否与当前业务相符；向一线追问其是否参与过方针制定或修订的意见征询；观察方针宣贯后是否产生了可核查的行为变化，如作业禁令、报告义务与防护要求的落实 |
| 常见不符合项 | 方针套用模板，与本组织业务、场所和重大风险无关；方针缺少法律法规符合或持续改进承诺的表述；方针由安全部门代笔，未经最高管理者批准即发布；方针宣贯集中于建体系当年的一次性培训，日常无沟通动作；一线员工能背诵口号却说不出与本岗位的关系；方针与战略、目标、预算互不关联，仅挂在手册首页；方针长期不评审，工艺与场所已变而方针不变 |
> 待核实：5.2 的正式条款标题与内容范围，以及其与 5.1、5.3、5.4 的条款划分，须用正版正文逐条核定。

#### 5.3 组织的角色、职责和权限

| 项目 | 内容 |
|---|---|
| 审核问题 | 组织如何确定并分配职业健康安全管理体系中各层级的角色、职责和权限？最高管理者、体系归口管理部门、各职能部门、各场所与岗位的职责是否明确到可核查的层面？各岗位所需能力要求是否与所承担的职责相匹配？职责分配是否已沟通、传达并被相关人员所理解？职责是否覆盖协商与参与、内部审核、管理评审、事件报告等关键角色？ |
| 需索取书面证据 | 组织机构图与职业健康安全职责分配表；岗位说明书与各层级职责文件，含最高管理者、体系归口部门、各职能部门与场所的职责权限界定；关键角色任命文件（体系负责人、内部审核员、工作人员代表、设备与计量管理员、事件报告责任人）；岗位能力要求与培训要求的对应矩阵；职责分配表的下达、宣贯与确认记录；职责调整时的变更与再沟通记录 |
| 现场核查证据 | 向各层级负责人分别追问其在体系中的职责边界与授权事项，核对是否与职责文件一致；抽查某一具体职责（如作业许可签发、隐患处置、事件上报）是否确实由文件规定的人员在实际行使；观察内部审核员、工作人员代表等被指定角色是否真实履职并留下履职痕迹；核对职责文件所列岗位是否全部为在编在岗人员、有无空缺或兼任冲突；向一线员工了解其对自身报告义务与升级路径的知晓情况 |
| 常见不符合项 | 职责文件只到部门未到岗位，或职责描述停留在“负责安全工作”等空泛表述；体系整体责任被默认推给安全部门，最高管理者的职责未落到文件与决策记录中；关键角色无任命文件，或名义上的内部审核员、工作人员代表从未实际履职；职责分配与实际分工不符，文件与现场存在两套口径；职责分配后无沟通与培训，相关人员不知自己负责什么；职责出现空缺无人替补，关键岗位人员轮岗后长期无人承担 |
> 待核实：5.3 的正式条款标题与内容范围，以及其与 5.1、5.2、5.4 的条款划分，须用正版正文逐条核定。

## 取证难度分级

本节只收录证据**需跨部门追溯、易于事后补造、或文件查不出只能靠现场反查**才能确认的条款。难度含义：**高** = 书面证据基本无法自证，必须现场穿透与交叉验证；**中** = 有书面载体但需抽样反查或第三方比对；**低** = 书面证据存在但需跨口径核对才能坐实。

| 条款号 | 难度 | 理由 |
|---|---|---|
| 4.1 理解组织及其所处的环境 | 中 | 环境识别清单易停留在建体系当年，静态文件齐备但动态更新情况需跨生产、设备、人力、采购、环保多部门口头访谈反查 |
| 4.2 理解工作人员和其他相关方的需求和期望 | 高 | 相关方需求与期望由本组织自述，真伪须向客户、供方、监管方外部取证核对，本方文件无法自证 |
| 4.4 职业健康安全管理体系 | 中 | 体系策划与过程说明文件可查，但体系过程是否真实运行、与方针目标风险的衔接是否成立，须向各过程负责人取证反查 |
| 5.1 领导作用和承诺 | 高 | 领导承诺无直接证据形式，须用访谈、知识掌握度、批示落实情况与资源投向联合反查，文件签署可轻易伪造 |
| 5.2 职业健康安全方针 | 中 | 方针文本与批准发布记录可查，但落实情况须查沟通记录、员工知晓度与资源投入 |
| 5.3 组织的角色、职责和权限 | 低 | 职责分工文件与授权文件可查，但实际履职须向各部门负责人取证反查 |
| 5.4 工作人员的协商和参与 | 高 | 参与记录属组织自产，只能无预告随机访谈一线与承包商员工验证深度与反馈闭环 |
| 6.1 应对风险和机遇的措施 | 高 | 危险源辨识与风险和机遇评价结论需与现场实际危险源逐项比对，须跨安全、工艺、设备、属地部门联合走线，纸面分级与现场实况常不一致 |
| 6.2 职业健康安全目标及其实现的策划 | 低 | 目标本身可查，但分解值与实际完成值分散在各部门绩效表与现场统计中，须跨部门逐条比对口径才能坐实，核对不到位极易以纸面数字掩盖未达标 |
| 7.2 能力 | 中 | 培训记录、证书、签到表均可查，但培训有效性只能通过现场操作演示验证，且需核外包方人员资质真伪 |
| 7.3 意识 | 高 | 意识无法留痕，任何书面材料都是自证，只能现场随机抽问班组与一线员工，看其能否说出本岗位风险与应急处置 |
| 8.1 运行策划和控制 | 高 | 变更管理、作业许可、设备点检类记录可事后补造且时间戳可调整，须现场比对实物状态、作业习惯与许可签批时序 |
| 8.2 应急准备和响应 | 中 | 预案与演练记录可查，但应急物资完好性与人员真实反应能力必须现场实操与实地核查，跨后勤与保卫部门取证 |
| 9.1 监视、测量、分析和评价绩效 | 高 | 绩效与合规性数据可修约、可重算，统计口径易被调整掩盖偏离，须追原始检测记录、点检记录与系统导出交叉复算 |
| 9.2 内部审核 | 高 | 审核报告与不符合项可写成样板，真实有效性须向被审核部门与被审核人分别取证比对，并核查审核员独立性 |
| 9.3 管理评审 | 高 | 评审输入输出多为汇总性结论，真实性靠追溯各输入源文件与向参会中层取证发现，只能间接反查 |
| 10.1 总则 | 中 | 过程文件易写，真实执行情况需查不符合项台账闭环与外部报告回执，跨安环、人力、法务取证 |
| 10.2 事件、不符合和纠正措施 | 高 | 根本原因分析与有效性验证易流于文字，须现场核纠正措施实物落地状态，并向当事岗位人员取证真实因果 |
| 10.3 持续改进 | 低 | 改进项目是否真落地只能现场反查，核验收数据须跨改进提出部门与受益现场双向走访，书面立项材料易与现场实况脱节 |
