# ISO 9001 / GB/T 19001-2016 条款级审核点基线

> 用途：「ISO 质量审核员全流程审核智能体」项目的审核知识库基线。
> 每个审核点都绑定：**具体标准条款号 → 现场审核问题 → 需索取的书面证据 → 现场核查证据 → 常见不符合项（NC）**。
> 覆盖 GB/T 19001-2016（等同采用 ISO 9001:2015）第 4～10 章全部条款，共 **27 张条款级审核表**（覆盖 55 个条款/子条款单元），另设 **1 个 8.7 编号口径说明块**。

---

## 1. 文档说明

### 1.1 适用范围

- 审核类型：依据 GB/T 19001-2016 / ISO 9001:2015 开展的**管理体系认证审核**（初次第一阶段、初次第二阶段、监督审核、再认证），同时可作为组织内部审核（第二方审核）的检查表参考。
- 依据文件：GB/T 19001-2016《质量管理体系 要求》（等同采用 ISO 9001:2015）、GB/T 19011-2021《管理体系审核指南》（等同采用 ISO 19011:2018）、CNCA《质量管理体系认证规则》。
- 不适用：产品认证（CCC）以及特定行业扩展要求（IATF 16949、ISO 22163 等）。此类要求是在 GB/T 19001 之上叠加行业条款，本基线不作覆盖。

### 1.2 方法论与准确性声明（重要）

1. **标准正文受版权保护**：GB/T 19001-2016、GB/T 19011-2021、ISO/IEC 17021-1 均受版权保护，本机未能取得标准正文全文（国家标准全文公开系统对采标国标不提供在线阅读，见 S1、S2）。因此本文件的条款**标题与要求要义**依据公开的条款结构、各认证与审核机构公开指南、CNCA 规则逐条对应重建，**不是标准原文的复制**。
2. **审核点是二次加工推导**：每个审核点由「标准条款意图」×「CNCA 规则强制的审核动作」×「ISO 9001 审核实践组（APG）已发布的审核指南主题」三方交叉推导，属于工程性产物，上线前应由持证审核员按本机构检查表复核。
3. **条款编号一致性**：GB/T 19001-2016 与 ISO 9001:2015 条款编号一致。ISO 9001:2015 在 4、5、6、9、10 章大量使用**扁平条款**（如 4.1～4.4、5.1～5.3、6.1～6.3、8.1、9.2、10.1、10.3 不设编号子条款），本基线对这些条款按单条处理；第 8 章「不合格输出的控制」在公开资料中存在 **8.6 与 8.7 两种编号口径**，本文件以 8.6 为主键、8.7 为别名块，**必须以正版标准目录核定**（见第 9.1 条）。此外 **7.5（成文信息）与 8.1（运行策划和控制）在 2015 版中未设编号子条款**，本文件对这两条按「内容块」编排（7.5 拆 3 块、8.1 拆 4 块），块内一律写「块①」而不写成 7.5.2、8.1.3 一类的条款号。8.4.2、7.1.5、9.3.2、10.2.2 一类的三级编号虽有较高把握，仍未经正本核对，**不得直接用作数据库主键**（入库别名见 1.4）。
4. **两处常见编号误解纠偏**（供智能体知识库清洗，务必核对）：
   - 8.4.1 在 ISO 9001:2015 中是**「总则」**，不是「控制外部提供的过程、产品和服务」。控制类型与程度在 **8.4.2**，应向外部供方提供的信息在 **8.4.3**。
   - 8.2 只有 **4 个子条款**：8.2.1 顾客沟通、8.2.2 产品和服务要求的确定、8.2.3 产品和服务要求的评审、8.2.4 更改。**不存在 8.2.5 与 8.2.6**。

### 1.3 字段定义

| 字段 | 含义 | 审核员用法 |
|---|---|---|
| 审核问题 | 现场向被审核方提出的开放式提问 | 形成访谈记录，是审核证据链起点 |
| 需索取的书面证据 | 应正式调阅的文件与记录清单 | 编制审核证据清单，可要求受控副本 |
| 现场核查证据 | 现场观察、追溯、核对的对象 | 抽样追记录：从成品或交付物反查记录，再从要求正查实施 |
| 常见不符合项 | 典型 NC 表述模板 | 写不符合项报告，须含「客观事实 + 违反条款 + 影响」三要素 |
| 难度 | 高 / 中 / 低，指**取证难度**（客观证据是否可得、是否需跨部门追溯、是否依赖主观陈述） | 决定审核时间分配与抽样强度，见第 8 节 |

**对智能体数据模型的三条硬要求**：

1. 条款号必须是可版本化主键，例如 clause_id = 7.1.5，standard_ref = GB/T 19001-2016，iso_ref = ISO 9001:2015，便于将来建立「19001-2016 → 新版」的条款映射表而不丢历史数据。

## 4. 通用取证方法（适用于全部条款）

### 4.1 审核范围的确定（依据 S6）

审核范围四要素：**实际位置（场所）、组织单元、活动和过程、覆盖的时期**。QMS 场景下范围宜覆盖：产品与服务范围（结合法定许可与资质等级）；业务活动范围（管理活动、资源提供、产品实现、测量分析改进）；管理职能范围（职能部门、岗位、分公司、临时项目部或工作组）；现场区域范围（固定场所、临时场所如工地、流动性服务如运输、多场所）；法律法规覆盖的外部区域；覆盖时间段（按审核目的为初次或监督），以充分适当证据为原则。

### 4.2 审核时间与现场时间（依据 S7、S3、S4）

- 1 人日 = 8 小时。有效人数含固定、临时、兼职、承包商人员及每班次人员，兼职与承包商可按实际工时折算。
- **现场审核时间不低于计算审核时间的 80%**（S7 第 2.1.2 条；S3 第 4.2.1.2 条）。远程审核须遵循 CNAS-CC14，且初次认证与通常的年度监督、再认证**必须含现场审核**（S7 第 4.5 条）。
- 监督审核约为初次审核时间的 1/3 且不少于 1 人日（S7 第 5 条；S3 第 5.3 条）；再认证约为 2/3 且不少于 1 人日（S7 第 6 条；S3 第 6.2 条）。
- 实习审核员、技术专家、观察员的时间不计入审核时间（S7 第 3.8 条；S3 第 4.2.2.2 与 4.2.2.3 条）。
- 新版规则口径（S4 第 11 问）：因低风险可减少，但减量不超过附录 B 时间的 10%；其他理由减少总计不超过 30%；工作日不足 8 小时须与委托人就调整至 8 小时达成一致并留记录。

### 4.3 证据等级与抽样原则

1. **证据优先级**：客观证据（记录、实物、现场观察）优先于口头陈述；口头陈述须由客观证据佐证，否则只能记为信息而非证据。
2. **双向追溯**：从成品或交付物反查过程记录以证明输出受控，从要求与目标正查实施记录以证明策划落实。CNCA 明确要求第二阶段审核**实际工作记录的真实性**，对真实性存疑的证据应予以记录，并在做出审核结论及认证决定时予以考虑（S3 第 4.3.3.5 条第 4 项）。
3. **抽样**：S3 第 4.2.3.2 条规定多场所抽样条件，不同场所活动存在明显差异或存在可能显著影响的区域性因素时**不得抽样**，须逐一现场审核；S8 第 5.3.1 条要求结合审核时按每个体系的要求分别确定现场与样本，不得只按经济性抽样。
4. **真实性预警特征**（供智能体自动标记）：S15 把编造记录、伪造审核记录、未到现场即出报告列为严查对象。工程上可关注的信号包括同一批次记录笔迹或系统时间戳异常整齐、记录编号连号倒挂、审批时间早于作业时间、补记痕迹、照片与现场设备型号不符。

### 4.4 不符合项分级与写法

- 分级口径可参考 S10（CNAS-GL008:2018）附录 A：严重不符合对应体系性失效、重大影响产品或服务符合性、法律法规符合性；一般不符合对应单点或局部失效。
- 认证规则门槛：严重不符合的纠正与纠正措施须在**最长 6 个月内**完成并验证有效性（S3 第 4.5 条）；若 6 个月内未完成验证，按第 4.6.5 条处理或重新实施第二阶段。
- 认证决定前必须逐项确认的四类情形（S3 第 4.6.3 条）：持续改进有效性存在缺陷或质量目标有重大疑问；质量目标不可测量或测量方法不明确；对实现质量目标有重要影响的关键点监视测量未有效运行，或其报告与评审记录不完整或无效；其他严重不符合。

## 5. 条款级审核点基线

### 5.0 阅读说明

- 每条款一个小节，含一张表：审核问题（现场问什么）／需索取的书面证据／现场核查证据／常见不符合项。
- 表下「难度」指取证难度；「APG 参考」指 ISO 9001 审核实践组已有同主题审核指南，可作为审核员准备材料（本地镜像只记录了主题文件名与发布时间，见 S5、S18；PDF 正文需另行获取）。
- 编号说明：GB/T 19001-2016 与 ISO 9001:2015 条款号一致。本基线只使用**条款级与子条款级编号**（如 8.4.2、7.1.5）。GB/T 19001-2016 个别条款下的更细分编号（如 6.1、6.2、7.1.5 内的次级条目）本地无法逐条核对正本，本文件用「6.1-① 识别风险和机遇」这类块内编号表示，落地前须以正版标准核定编号。

### 5.1 第 4 章 背景（4.1～4.4）

#### 4.1 组织环境

| 项目 | 内容 |
|---|---|
| 审核问题 | 组织如何确定与其宗旨和战略方向相关的内部和外部因素？这些因素如何影响质量管理体系实现预期结果的能力？气候变化相关考虑如何纳入（ISO 9001:2015 Amd 1:2024 修订涉及 4.1 与 4.2）？ |
| 需索取的书面证据 | 组织环境分析记录（PEST/SWOT、竞争与市场分析）、内外部因素清单及更新记录、相关方分析与需求矩阵、气候相关性与法规要求影响的评价记录、管理评审中环境变更的输入记录 |
| 现场核查证据 | 查看分析记录形成日期与最近一次更新日期；抽查其列举的因素是否真实影响体系（对照当期的订单结构、法规变化、人员状况）；核对分析结论是否向下传递到 6.1 风险识别与 6.2 质量目标 |
| 常见不符合项 | 组织未系统识别内外部因素，仅列行业宏观口号；环境分析长期未更新，与当前经营实际脱节；相关方清单遗漏关键方（如监理单位、行业协会、供方）；已发生的重大环境变化未反映到风险与目标中 |

#### 4.2 理解相关方的需求和期望

| 项目 | 内容 |
|---|---|
| 审核问题 | 组织如何监视、解释并确定相关方的需求和期望？其中哪些转化为产品与服务要求、法规要求或过程要求？如何向相关方沟通并处理相互冲突的要求？ |
| 需索取的书面证据 | 相关方清单与要求监视记录、顾客与法规要求的评审与转化记录、要求冲突的处置记录、向相关方反馈结果的记录 |
| 现场核查证据 | 访谈销售、合同、售后人员，追溯一件已交付产品/服务当时承诺的要求；核对相关方要求是否逐条落入合同评审与 8.2.2 要求的确定 |
| 常见不符合项 | 相关方要求仅笼统记录为「顾客满意」，无具体要求项；未对要求变化做监视；法律法规变化（如新强制性标准）未转化为体系要求；冲突要求未形成决定并记录理由 |

#### 4.3 确定质量管理体系的范围

| 项目 | 内容 |
|---|---|
| 审核问题 | 体系范围如何确定并文件化？是否覆盖全部场所、活动、过程、产品与服务？范围描述是否与实际一致（第一阶段核对的重点，见 S3 第 4.3.3.2 条第 1 项）？ |
| 需索取的书面证据 | 质量手册或体系说明中的范围条款、场所与活动清单、认证范围申报文件、删减条款的说明与理由（如 7.3 意识、8.3 设计开发等删减） |
| 现场核查证据 | 将范围文件与现场比对：部门、场所、生产服务活动、班次是否都被覆盖；验证删减条款是否确属不适用且理由成立 |
| 常见不符合项 | 范围描述与现场实际不一致（漏场所、漏临时场所、漏一班制人员）；范围声明不符合法规允许的删减边界；新增场所或业务未纳入范围而仍使用证书 |

#### 4.4 质量管理体系及其过程

| 项目 | 内容 |
|---|---|
| 审核问题 | 组织是否按过程方法确定过程的输入输出、顺序和相互作用、准则和方法、资源、职责权限、风险和机遇、绩效指标与改进方式？成文信息如何支撑？哪些过程外包，外包如何受控？ |
| 需索取的书面证据 | 过程清单与过程关系图、过程说明（准则、方法、绩效指标、负责人）、外包过程识别清单及外包控制方案、过程绩效监视数据 |
| 现场核查证据 | 选一条实际订单或一件产品做端到端追踪，验证过程图与实际流转一致；核对绩效指标是否有真实数据支撑而非空表 |
| 常见不符合项 | 过程清单与实际作业不符；过程无明确准则与绩效指标；外包过程（如委外加工、外包物流、外包检测）未识别或无控制方式；过程之间的关系未描述，导致接口失控 |

### 5.2 第 5 章 领导作用（5.1～5.3）

#### 5.1 领导作用和承诺（含 5.1.1 总则、5.1.2 相关方导向）

| 项目 | 内容 |
|---|---|
| 审核问题 | 最高管理者如何对体系有效性负责？如何确保方针目标相容、体系要求融入业务过程、以过程方式管理、获得预期结果并促使人员参与和推动改进？最高管理者是否亲自参与（APG 有 2025-03-21 最高管理者专题材料）？ |
| 需索取的书面证据 | 最高管理者对体系的声明与任命文件、资源投入决定（预算、人员编制、设备）、与战略方针的相容性论证、最高管理者主持的管理评审记录、内审启动与人员任命文件 |
| 现场核查证据 | 与最高管理者单独面谈，核对其对体系关键风险、重大不符合与资源约束的了解程度；查其签署的决策记录是否与访谈陈述一致；查一线人员是否能说出最高管理者的具体要求 |
| 常见不符合项 | 最高管理者仅挂名，访谈中对体系运行细节不了解；资源投入不足以支撑目标；最高管理者未主持或未实质参与管理评审与内审；体系要求未嵌入日常业务决策（战略、经营计划中无质量要求） |

#### 5.2 方针（含 5.2.1 总则、5.2.2 方针的建立与沟通）

| 项目 | 内容 |
|---|---|
| 审核问题 | 方针是否适宜战略与运行环境、构成质量目标的框架、满足法律法规要求、包含持续改进承诺？方针如何沟通、理解并在组织内保持一致？ |
| 需索取的书面证据 | 方针文本、发布与批准记录、方针与战略相容性的评审记录、方针沟通与宣贯记录、员工理解确认（培训签到、考试、班组记录） |
| 现场核查证据 | 现场抽查 3 至 5 名不同层级员工，请其用自己的话说明方针含义及其与本岗位的关系；查看车间看板、看板、作业文件上的方针是否一致 |
| 常见不符合项 | 方针模板化、与战略和业务无关；缺少法律法规符合或持续改进承诺；方针变更后未重新沟通；员工只知道口号说不出与岗位的关联 |

#### 5.3 组织的岗位、职责和权限

| 项目 | 内容 |
|---|---|
| 审核问题 | 相关岗位的职责权限是否规定并传达？质量管理者、过程负责人、内审员、合规人员的指定与授权是否清晰？跨部门接口的职责是否明确？ |
| 需索取的书面证据 | 组织机构图与部门职责文件、岗位说明书、内审员与质量管理者任命文件、授权文件（放行、不合格处置、对外供方批准、让步接收） |
| 现场核查证据 | 找 2 至 3 名一线员工核对其职责表述与文件是否一致；对授权事项抽查授权人本人是否在岗、是否实际行使 |
| 常见不符合项 | 职责权限文件与实际分工不符；关键授权（如产品放行、让步接收）无人行使或由不具备资格者行使；接口部门职责重叠或空白 |

### 5.3 第 6 章 策划（6.1～6.3）

#### 6.1 应对风险和机遇的措施（含识别、策划、有效性评价与融入三个块）

| 项目 | 内容 |
|---|---|
| 审核问题 | 组织如何识别影响体系预期结果的风险和机遇？识别方法是否覆盖过程、变更、外部因素？如何策划应对措施（规避、降低、分享、接受、追求）并评价其有效性？措施如何融入 8.1 运行策划、8.3 设计与开发、8.4 外部供方控制等既有过程？ |
| 需索取的书面证据 | 风险与机遇识别清单及其来源（过程评审、变更评审、内审、管理评审、员工建议）、风险评价准则与分级、应对措施计划及责任人、措施有效性评价记录、措施融入既有过程文件的对照说明 |
| 现场核查证据 | 抽取 3 项已识别风险，追问其来源与判定依据；查看措施在过程文件中是否真实存在（而非另起一套台账）；核查有效性评价是否用客观数据（缺陷率、交付及时率、审核发现数）而非仅写「已培训」 |
| 常见不符合项 | 风险清单与 4.1 环境分析、6.2 目标、内审发现互相割裂，同类问题重复识别；措施未融入实际流程，仅在风险台账中闭环；有效性评价无客观依据；只识别风险不识别机遇；变更未触发风险重评 |

#### 6.2 质量目标及其实现的策划（含 6.2.1 确定目标、6.2.2 策划实现）

| 项目 | 内容 |
|---|---|
| 审核问题 | 质量目标是否在相关职能、层次和过程上建立？是否与方针一致、考虑适用要求与法规、明确可测量（指标、计算方法、目标值、时限、资源、数据来源）？目标未达成时如何处置？ |
| 需索取的书面证据 | 目标分解表（层级到部门、岗位、过程）、指标定义与计算口径文件、目标下达与沟通记录、目标监视数据分析记录、未达成目标的处置与改进记录 |
| 现场核查证据 | 任选一个目标，现场要求被考核部门出示原始数据并复算指标（这是 CNCA 监管重点：编造记录，S15）；核对目标值与实际绩效的差距及其处置 |
| 常见不符合项 | 目标不可测量（无口径、无数据源、无时限）；目标只到部门未到过程；目标与法规强制要求脱节；目标数据与 9.1.3 的分析结论互相矛盾；未达标无分析无改进（CNCA 认证决定前须确认目标可测量且监视有效，S3 第 4.6.3 条） |

#### 6.3 变更的策划

| 项目 | 内容 |
|---|---|
| 审核问题 | 组织如何策划体系或过程的变更？变更前是否评价目的与潜在后果、对体系的影响、职责权限、资源需求与沟通安排？变更导致的成文信息更新是否同步？ |
| 需索取的书面证据 | 变更申请与评审记录、变更影响评价（含对目标、风险、过程的影响）、变更实施与验证记录、相关文件修订记录、变更通知与培训记录 |
| 现场核查证据 | 抽取近 6 至 12 个月的实际变更（工艺、设备、组织、人员、场所、供应商）逐项追溯其策划证据；核对变更后现场作业文件与新要求是否一致 |
| 常见不符合项 | 变更未评审直接实施；变更后文件、图纸、工艺参数未同步更新；变更对目标和风险的影响未重新评价；重大变更未按合同向认证机构通报（S3 第 4.1.5 条第 3 项） |

### 5.4 第 7 章 支持（7.1～7.5）

#### 7.1 资源（含 7.1.1 总则与 7.1.2～7.1.6 五个资源分项）

| 项目 | 内容 |
|---|---|
| 审核问题 | 组织如何确定并提供体系所需资源（7.1.1）？资源是否与 6.1 的风险机遇、6.2 的目标相匹配？人员（7.1.2）、基础设施（7.1.3）、过程运行环境（7.1.4）、监视测量资源（7.1.5）、组织知识（7.1.6）分别如何获取、维持并可用？ |
| 需索取的书面证据 | 资源需求分析与配置决定（人员编制、设备台账、场地与工位规划、监视测量设备台账与校准计划、组织知识清单）、基础设施与过程运行环境的维护保养计划与记录、监视测量资源的溯源链（校准证书、检定/校准周期、测量不确定度评估、不合格测量设备对以往结果的影响评估）、组织知识的保持方式（知识产权、经验教训库、技术档案） |
| 现场核查证据 | 现场核查设备实际状态与台账一致（贴标在有效期内、封存完好）；抽查一台关键测量设备从现场到校准证书的完整溯源链（校准证书—校准机构资质—溯源到国家/国际基准）；查维护保养与厂房设施的实际执行记录；查经验教训库是否被实际调用 |
| 常见不符合项 | 监视测量设备超期未校准仍使用；校准证书无溯源性说明或仅写「合格」；测量设备失效后未评估对已放行产品的影响；维护保养记录补填、代签、涂改；组织知识无载体（离职即丢失），无人员备份；基础设施故障影响交付无应急措施 |

#### 7.2 能力

| 项目 | 内容 |
|---|---|
| 审核问题 | 组织如何确定各岗位所需能力？如何获得能力（培训、辅导、咨询、学历、经历）？如何确保能力差距被有效补足？如何保留人员能力证据？ |
| 需索取的书面证据 | 岗位能力要求矩阵（岗位—所需知识/技能/经验—评价准则）、培训计划与实施记录、考核结果与合格判定标准、外部培训与资质证书、入职与转岗培训记录、特殊过程人员的资格评定记录 |
| 现场核查证据 | 抽 2 至 3 名关键岗位人员访谈其培训经历与资格是否与岗位要求匹配；核查培训记录与现场人员的一致性（有无代签）；验证特殊过程操作人员的资格评定证据（如焊接、热处理、无损检测） |
| 常见不符合项 | 能力要求只有通用培训计划、无岗位对应矩阵；培训记录事后补记、代签；特种作业/检验人员无有效资格或资格过期；能力评价结果不与岗位安排挂钩 |

#### 7.3 意识

| 项目 | 内容 |
|---|---|
| 审核问题 | 组织如何确保相关人员知晓质量方针、相关岗位的作用与职责、与其工作相关的顾客要求和法律法规要求、不合格控制与绩效改进的好处？ |
| 需索取的书面证据 | 方针与意识的宣贯记录、班组会/晨会记录、看板与公示栏照片、岗位责任告知书、新员工入职宣导记录 |

##### 5.5.1 8.7 编号口径说明块（别名映射，不新增审核点）

GB/T 19001-2016 / ISO 9001:2015 的第 8 章末条为「不合格输出的控制」，但公开资料（部分译本、行业课件与需求文档）中同时存在 **8.6 与 8.7 两种编号口径**。历史沿革：ISO 9001:2008 中 8.6 = 不合格品控制、8.7 = 数据分析；2015 版将数据分析并入 9.1.3，之后末条编号在公开转述中出现两种口径。本基线的处理：

| 事项 | 处理 |
|---|---|
| 主键 | 8.6（不合格输出的控制），按上表取证 |
| 别名 | 8.7 → 路由到 8.6 的审核问题与证据清单，不生成第二套问题 |
| 需求文档中的「8.7 纠正措施」 | 纠偏到 **10.2 不合格和纠正措施**（本文件 5.7 已单列），避免同一要求在两处重复取证 |
| 审核员提问口径 | 提问说「不合格输出的控制」，不念编号；报告中引用编号须与本机构检查表一致 |
| 上线前动作 | 以正版 GB/T 19001-2016 目录核定后回写 1.4 别名表与本块（见 9.1） |

#### 9.3 管理评审（含 9.3.1 总则、9.3.2 输入、9.3.3 输出）

| 项目 | 内容 |
|---|---|
| 审核问题 | 管理评审是否按计划由最高管理者主持、间隔是否符合要求（通常每年至少一次）？输入是否齐全（以往评审措施、过程绩效与产品服务符合性、顾客满意、外部供方绩效、监视测量结果、不符合与纠正措施、内审结果、外部因素变化、风险机遇与措施有效性、资源充分性、改进机会）？输出是否形成决策（改进机会、变更需求、资源需求）并落实跟踪？评审记录是否真实完整、是否包含体系有效性评价？ |
| 需索取的书面证据 | 管理评审计划与通知（含参加人员，含技术专家）、管理评审报告与签到表、各项输入材料及数据、评审输出决议与落实跟踪记录、改进事项的责任人与完成时间 |
| 现场核查证据 | 核实评审记录的真实召开（签到、议程、发言记录）；核对输入中的数据与 9.1.3 分析报告一致；追踪输出决议到落地（改进项目已在实施）；确认最高管理者对体系有效性的评价结论 |
| 常见不符合项 | 管理评审由管理者代表主持或最高管理者未实质参与；输入项缺失（无顾客满意、无外部供方绩效、无风险措施有效性）；评审只有「一致通过」无具体决议与资源承诺；输出决议无跟踪；评审记录事后补写；输入数据与实际绩效矛盾（目标未达成但评审称有效） |

### 6.4 与审核时间、成本的耦合（依据 S7、S3、S4，已获取）

- 1 人日 = 8 小时；有效人数含固定、临时、兼职、承包商与每班次人员；兼职与承包商可按实际工时折算（S3 附录 A、S7）。
- 现场审核时间 ≥ 计算审核时间的 80%；初次认证与通常的年度监督、再认证必须含现场审核（S7 第 2.1.2、4.5 条）。
- 监督审核 ≈ 初次审核时间的 1/3 且不少于 1 人日；再认证 ≈ 2/3 且不少于 1 人日（S7 第 5、6 条）。
- 实习审核员、观察员、技术专家时间不计入审核时间（S7 第 3.8 条）。
- 新版规则口径：因低风险可减少，减量 ≤ 附录 B 时间的 10%；其他理由减少总计 ≤ 30%；工作日不足 8 小时须与委托人就调整至 8 小时达成一致并留记录（S4）。

**推论（供智能体排程模块）**：审核时间不是「条款数 × 固定时长」，而是「有效人数 + 场所 + 过程复杂度 + 风险等级」的函数。条款级基线只能作为**时间分配的权重依据**，不能直接换算人日。

## 7. 第一阶段（资格审核）与第二阶段（现场审核）的取证重点差异

### 7.1 法规硬性要求对照（依据 S3 第 4.3.3 条、S4）

| 维度 | 第一阶段（Stage 1） | 第二阶段（Stage 2） |
|---|---|---|
| 目的 | 确认体系文件化信息与现场实际一致、体系已实施并运行、具备实施第二阶段的条件 | 验证体系实施与运行的有效性，形成符合性结论与不符合项 |
| 地点 | **原则上现场**；仅三种情形可非现场：①已获本认证机构颁发的其他管理体系领域有效认证证书；②技术特征明显、过程简单，且文件审查可达到目的；③持有其他认可机构颁发的证书，且文件审查可达到目的。采取非现场方式须记录理由（S3 第 4.3.3.3 条；新版 FAQ 补充了第 ①项条件，S4） | **必须在现场**（S3 第 4.3.3.5 条） |
| 时机条件 | 须确认体系已运行**超过 3 个月**（证据时间从取得营业执照后计算，S3 第 4.3.3.2 条第 2 项、S4） | 体系运行不足 3 个月或成文信息与现场不符的，**不应实施第二阶段**（S3 第 4.3.3.2 条） |
| 审核计划 | 不要求编制正式审核计划（S3 第 4.2.3 条末段）；但须形成书面文件并告知组织，同时提醒重要关键点（S3 第 4.3.3.4 条） | 须编制正式审核计划，至少含目的、准则、范围、现场日期与场所、持续时间、审核组成员（审核员标明注册号、技术专家标明专业代码/单位/职称）（S3 第 4.2.3 条） |
| 取证方式 | 文件评审 + 现场走访 + 关键人员访谈；查「纸面与现场是否一致」 | 现场观察 + 记录追溯 + 人员访谈 + 证据抽样；查「实际运行是否有效」 |
| 必须覆盖的五项 | ①核对成文信息与现场的一致性（产品服务、部门设置、职责权限、生产服务过程）；②审核对 GB/T 19001 要求的理解与实施，评价内审与管理评审是否已实施，确认体系运行已超过 3 个月；③确认体系覆盖的活动范围与内容、有效人数、过程、场所，以及遵守适用法律法规与强制性标准的情况；④识别对质量目标实现有重要影响的关键点，并科学确定重要审核点；⑤讨论确定第二阶段安排 | ①一阶段识别的重要审核点的过程控制有效性；②质量目标是否具体适用、可测量、已沟通、已监视；③对所覆盖的过程和活动的管理与控制；④**实际工作记录的真实性**（存疑证据应记录，并在结论与认证决定中考虑）；⑤内审与管理评审是否有效 |
| 抽样 | 以文件与范围比对为主，不做过程抽样 | 按范围与风险抽样；多场所抽样须满足条件，场所活动存在明显差异或区域性显著影响因素时**不得抽样**，须逐一审核（S3 第 4.2.3.2 条） |
| 输出 | 第一阶段书面文件（发现、结论、第二阶段重点提醒） | 审核报告（8 项内容）、不符合项清单、通过意见（S3 第 4.4.1 条）；严重不符合的纠正与纠正措施 ≤ 6 个月并须验证有效性（S3 第 4.5 条） |
| 可否终止审核 | 具备条件则进入第二阶段；不具备应停止并说明 | 终止审核三情形：不配合、实际与申请材料重大不一致、其他（S3 第 4.3.4 条） |

### 7.2 取证重点的实务差异（供智能体分阶段生成清单）

| 审核内容 | 第一阶段重点 | 第二阶段重点 |
|---|---|---|
| 范围与场所（4.3、4.4） | 成文范围声明 vs 实际部门/场所/活动的**一致性**；范围边界；删减条款的适用性 | 范围内过程是否全覆盖；抽样是否触及所有过程类别；场所覆盖是否与多场所方案一致 |
| 过程方法（4.4、8.1） | 过程清单是否覆盖申请范围与全部过程；过程图与实际流程是否**基本吻合** | 过程准则、方法、资源、职责、绩效指标是否**实际运行**；接口与外包过程的有效性 |
| 顾客与法规要求（4.2、8.2） | 法规清单是否识别；合同/要求识别机制是否存在 | 合同评审的**真实性**与能力确认；变更通知；顾客投诉与要求转化的闭环 |
| 资源与能力（7.1～7.3） | 设备台账、测量设备校准**覆盖率**、人员编制与培训计划的**存在性** | 现场设备实际状态与校准有效性、溯源链完整性、岗位能力与培训记录的**真实性** |
| 成文信息（7.5） | 文件清单与外来文件清单是否存在；审批流程 | 现场使用的版本是否为现行版；外来文件更新是否落地；电子记录是否防篡改 |
| 绩效与改进（9.1、10.2、10.3） | 目标与指标体系是否存在、是否有数据 | 指标口径与原始数据是否可复算；未达标是否分析；纠正措施是否到体系层面且经验证 |
| 内审与管理评审（9.2、9.3） | 是否已实施、时间是否满足（体系运行 3 个月内需已实施） | 内审覆盖与不符合项闭环质量；管理评审输入输出完整性、输入与 9.1.3 数据一致性、决议落地 |
| 外部供方（8.4） | 是否已识别外部提供过程与产品、评价机制是否存在 | 评价与再评价的实际执行、进货检验、委外过程控制证据链 |

### 7.3 第一阶段与第二阶段共享的「红线」（智能体应主动拦截）

1. 成文信息与现场实际重大不一致 → 不得进入第二阶段（S3 第 4.3.3.2 条）。
2. 体系运行未超过 3 个月 → 不得进入第二阶段（S3、S4）。
3. 证据真实性存疑 → 必须记录，并在认证决定中考虑（S3 第 4.3.3.5 条第 4 项）；CNCA 2026 年监管通知把「编造记录、伪造审核记录、未到现场即出报告」列为严查对象（S15）。
4. 质量目标不可测量或测量方法不明确 → 属认证决定前必须确认的情形（S3 第 4.6.3 条）。
5. 认证决定人员与审核组成员不得重叠（S3 第 4.6.2 条）。

### 8.4 不符合项表述规范（可直接用于智能体生成 NC 草稿）

依据 S10（CNAS-GL008:2018 附录 A）的不符合项分级与示例写法，迁移到管理体系认证审核场景：

- 严重不符合（对应体系性失效）：例如「组织未建立覆盖申请范围全部过程的成文信息，4.4 与 7.5 要求未满足，导致无法证明过程受控」。
- 一般不符合（对应单点/局部失效）：例如「××工序作业记录为事后补填，8.5.1 与 7.5 要求未满足」。
- 每条 NC 三要素：**客观事实（含证据与样本量）＋违反的标准条款＋对体系有效性的影响**。
- 引用 S10 中的典型表述作对照（实验室场景，迁移时需改写）：「无法提供合格供应商的评价记录」「内审发现的不符合项仅纠正未分析原因并采取纠正措施」「记录错误用涂改液修改未杠改签字」「管理评审报告中缺少管理体系适用和有效性评价」。
- 观察项与改进建议应与不符合项分列（S11 内审发现四分类：支持证据、不符合、观察项、改进建议）。
- S11 的纠正措施验证标准可直接沿用：**有证据表明措施已实施，且不符合未重复发生**。

### 8.5 对「全量审核清单」规模的结论

1. **条款覆盖已完整，但单次审核无法全覆盖**：55 个审核点对应 350～450 条证据项，受审核时间（S7、附录 B）限制，一次现场审核通常只能取证其中 20%～40%。因此基线的正确用法是「**全量清单 + 按风险与范围动态选取**」，而不是逐条线性执行。
2. **真正的杠杆在 12 个高/中高难度条款**：8.4.2、8.5.6、8.5.3、8.2.3、9.1.3、10.2.2、6.2、9.3、7.1.5、8.3、8.1、9.2。它们同时占「审核发现风险」和「审核时间」的绝大部分。
3. **智能体最能创造价值的不是条款清单本身，而是三件事**：(a) 条款 → 证据清单 → 现场追溯动作的映射；(b) 证据真实性校验（防伪造、防补记）与复算提示；(c) 不符合项草案生成（客观事实 + 条款 + 影响 + 分级建议）。
4. **条款级编号必须可版本化**：clause_id + standard_ref 双字段（S13、S1），以便 GB/T 19001-2016 与 ISO 新版条款映射。
