# Triage Labels

技能用五个规范 triage 角色说话，本文件把这些角色映射到本仓库 issue tracker 里实际使用的标签字符串。

| 技能里的标签 | 本仓库的标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估这个 issue |
| `needs-info` | `needs-info` | 等报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 已完全指明，可交给 AFK agent |
| `ready-for-human` | `ready-for-human` | 需要人来实现 |
| `wontfix` | `wontfix` | 不做 |

技能提到某个角色时（例如「打上 AFK-ready 的 triage 标签」），就使用上表对应的标签字符串。

要换成本仓库已有的其他叫法时，改「本仓库的标签」这一列即可。
